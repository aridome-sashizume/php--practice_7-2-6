# php-control-practice

## 概要
COACHTECH 教材 Tutorial 7-2「制御構文 ハンズオン演習」で作成した成果物です。
PHOを用いた成績判定システムです。
二次元配列に個人成績を格納し、関数を用いて成績を判定するプログラムです。

## 使用技術
- PHP 8.2
- 
## 学んだこと
-PHPを用いた関数による判定方法を学びました。
-ループ文を用いて配列に格納するユーザすべてを関数にお代入することができること
-PHPが引数指定を型指定しなければ、プログラムが自動的に型を読み取って処理を行う

## 動作確認
dockerを用いてWSL2のサーバを設定し、localhost:8000のポートを開く <br>
その上で以下でWebページにアクセスする。 <br>
http://localhost:8000/7-2-6_hands_on/practice/grade_calculator.php
